# How To Make A Media Suite?
My current setup for a media suite is a Jellyfin instance on localhost, and I have been using [Feishin](https://github.com/jeffvli/feishin) to listen to my music. And while I have not yet tried extending this setup with movies or ebooks, I imagine it could be done rather easily.

Generally, I dont want to reinvent the wheel. So for the time being, the above stack *works*. But in the future we could replace Feishin and the Jellyfin client with apps built with our own design principals.

<hr>

* Music listening app.
* Movie/Tv Show/Video watching app.
* Ebook App

All hook into a localhost jellyfin server.
